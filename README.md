Vortex is a full-stack social media application I designed, developed, and deployed using Python, FastAPI, PostgreSQL, JavaScript, HTML, and CSS. The platform allows users to create profiles, share posts, upload images, follow other users, like and comment on content, bookmark posts, exchange messages, and receive notifications.

The backend features RESTful APIs, JWT authentication, OAuth2, password hashing, email verification, and database management using SQLAlchemy and Alembic. I implemented automated testing with pytest, Docker for containerized development, and GitHub Actions for CI/CD.

The application is deployed on a Linux server using Nginx, Gunicorn, Uvicorn, and Cloudflare with HTTPS. This project strengthened my experience in full-stack development, database design, API security, automated testing, and production deployment.
